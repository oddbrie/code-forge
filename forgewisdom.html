Box Model

Every element is a box. The box model is one of the most important CSS concepts.

contentpaddingbordermargin
Content
The actual text, image, or child elements.
Padding
Space between the content and the border.
Border
The visible edge around the padded box.
Margin
Space outside the border, separating elements from each other.
Width / Height
Control the size of the content box unless box-sizing changes the behavior.
Border Radius
Rounds corners to make boxes softer.

Layout: Flexbox, Grid, and Positioning

Layout tools help you place content on the page in an intentional, maintainable way.

Flexbox

Flexbox is best for one-dimensional layout, such as items in a row or a column.

display:flexjustify-contentalign-itemsgap
Code Example

  align-items: center;
  gap: 12px;

DOM Update Example

JavaScript can find an element and change its text, classes, styles, attributes, or content after a user action.

document.getElementByIdtextContentaddEventListener
Code Example
<button id="btn">Click me</button>
<p id="status">Waiting...</p>

const btn = document.getElementById("btn");
const status = document.getElementById("status");

btn.addEventListener("click", () => {
  status.textContent = "Button clicked.";
});
What Happens

In a real page, clicking the button would change the paragraph text from Waiting... to Button clicked.

Common JavaScript Jobs in Web Apps

JavaScript is not just for buttons. It often connects the user interface to backend APIs.

Event handling
Click, input, submit, hover, keyboard events.
DOM updates
Change text, show or hide sections, render lists, swap classes.
API calls
Request JSON from a server and display the returned data.
Validation
Check that form values are complete and correct before submitting.
State changes
Track toggles, tabs, selected items, cart contents, filters.
Async behavior
Wait for responses, timers, uploads, or background processes.

Mapping Web Concepts to Kotlin, Java, and Python

Since you are already in software development, this section connects frontend ideas to the backend and app-development perspective.

Frontend ↔ Backend Flow

The browser displays UI, but it often depends on a backend service for real data and business logic.

Concept Flow
Browser page (HTML/CSS/JS)
        ↓
User clicks button or submits form
        ↓
Frontend sends request to API
        ↓
Backend validates, processes, reads database
        ↓
Backend returns JSON response
        ↓
Frontend updates the page
Why this matters
  • HTML shows the structure of the page
  • CSS controls how it looks
  • JavaScript decides what happens next
  • Kotlin / Java / Python often power the server-side logic

Language Snapshots

Each of these languages can appear in a modern software stack, but they usually play different roles.

Kotlin

fun main() {
    val user = "Aubrie"
    println("Hello, $user")
}

Kotlin is strong for Android and also backend work through frameworks like Ktor and Spring Boot.

Java

public class Main {
  public static void main(String[] args) {
    String user = "Aubrie";
    System.out.println("Hello, " + user);
  }
}

Java is common in enterprise systems, REST APIs, and large-scale backend applications.

Python

user = "Aubrie"
print(f"Hello, {user}")

Python is popular for scripting, automation, data work, and backends using Flask or Django.
